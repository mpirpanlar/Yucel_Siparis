# CRM - Potansiyel Müşteri Listesi

**FormName:** `CrmPotansiyelListesi`

## Bu ekran ne işe yarar?

Potansiyel müşteri kayıtlarını filtreleyerek listeler; seçim modunda diğer formlara aktarım yapar.

## Ne zaman kullanılır?

- Potansiyel arama ve kart açma
- Aktivite/rota formlarında potansiyel seçimi (Satır Seç)

## Filtreler

| Alan | Açıklama |
|------|----------|
| Firma / Unvan | Metin arama |
| Netsis kodu | Bağlı cari |
| Durum | Potansiyel durumu |
| Sadece Netsis bağlı | Filtre |

## Butonlar

| Buton | Açıklama |
|-------|----------|
| Listele | Grid doldurur |
| Satır Seç | Seçim modunda hedef forma döner |
| Kaydı Aç | Potansiyel kartı |
| Yeni Kayıt | Yeni potansiyel |
