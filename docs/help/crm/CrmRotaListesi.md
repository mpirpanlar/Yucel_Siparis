# CRM - Tanımlı Rota Planlamaları

**FormName:** `CrmRotaListesi`

## Bu ekran ne işe yarar?

Oluşturulmuş rota planlarını listeler; plan detayına geçiş sağlar.

## Ne zaman kullanılır?

- Geçmiş veya aktif rotaları görmek
- Rota kartını düzenlemek

## Grid kolonları

| Sütun | Açıklama |
|-------|----------|
| Başlık | Rota adı |
| Durum | TASLAK / ONAYLI / IPTAL |
| Plan tarihi | Ziyaret günü |
| Durak / Toplam km | Özet bilgiler |

## İlgili ekranlar

- CrmRotaPlan, CrmRotaKmRapor
