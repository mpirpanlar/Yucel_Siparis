# CRM - Kontrol Raporu

**FormName:** `CrmKontrolRapor`

## Bu ekran ne işe yarar?

Aktivite kontrol listesi cevaplarını filtreleyerek raporlar; eksik veya tamamlanmış maddeleri gösterir.

## Ne zaman kullanılır?

- Saha ziyaretlerinde kontrol listesi uyumunu denetlemek
- Yönetici özet raporu

## Filtreler

| Alan | Açıklama |
|------|----------|
| Tarih aralığı | Aktivite tarihi |
| Personel | Yapan / atanan |
| Aktivite tipi | Tip filtresi |
| Durum | Tamamlanma durumu |

## İş kuralları

- Rapor yalnızca kontrol listesi atanmış aktiviteleri kapsar.
- Tarih filtresi zorunludur.

## İlgili ekranlar

- CrmSoruSeti, CrmAktiviteRapor
